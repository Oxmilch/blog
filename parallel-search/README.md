# ParallelSearch
## 概要
色んなサイトで同じ検索ワードで検索する！っていう簡単なHTML。  
各サイトの検索パラメータを含めたURL自動的に生成するだけのもの。

## できること
・対応したサイトへの検索用URLの生成。  
・生成したURLの1クリック遷移。  
・生成したURLの1クリックコピー。  

## できないこと
・AND検索ワードなしでの検索。  
・サイトのトップページへの遷移。  
・スクレイピング（検索ワードから各サイトの情報取りません）  
・検索履歴の確認。  
・表示非表示のユーザー側での設定。  
・検索サイトのユーザー側での追加。
